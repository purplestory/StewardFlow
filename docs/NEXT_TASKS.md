# NEXT TASKS

## P0 (즉시)

### 1) 도서 마이그레이션 환경 적용 확인
- 상태: 완료 (2026-02-20)
- 완료 조건(AC):
1. 운영 환경에서 `book_items`, `book_loans` 존재 확인
2. 도서 홈(`/books`)에서 테이블 누락 오류 미노출
3. 도서 운영(`/books/manage`)에서 목록/승인/반납 조회 정상

### 2) 메뉴/정책 화면 시각 QA
- 상태: 진행 필요
- 완료 조건(AC):
1. `/settings/menu`, `/settings/org`, `/settings/users`에서 컴포넌트 간 간격/버튼 규격 일관
2. 모바일 폭에서 액션 버튼 줄바꿈/오버플로우 없음
3. 수정/삭제 액션이 아이콘 스타일로 통일되어 보임

### 3) 카카오 로그인 콜백 회귀 테스트
- 상태: 진행 중 (콜백 세션 복구 대기 로직 보강 완료, 실단말 QA 필요)
- 완료 조건(AC):
1. 로그인 시 "인증 실패" 페이지 깜빡임 재현되지 않음
2. 로그인 후 세션 유지(쿠키/재접속) 동작 확인
3. 실패 시 에러 처리 경로(`/login?error=...`) 일관 동작

### 4) 초대 만료 정책 마이그레이션 반영 확인
- 상태: 진행 필요
- 완료 조건(AC):
1. `organizations.invite_expires_days` 컬럼 존재 확인
2. `organization_invites.expires_at` 컬럼 존재 확인
3. 사용자 관리 화면에서 만료일 저장 후 신규 초대 만료 시각 반영 확인

## P1 (단기)

### 5) 도서 자율 대출/반납 UX 고도화
- 상태: 일부 구현됨

1. 대출: 스캔 기반 시작 플로우가 모바일에서 3탭 이내
