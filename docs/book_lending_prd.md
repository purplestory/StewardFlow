# 도서 대여 관리 기능 PRD (자율 대출/반납 + 메모 + AI 퀴즈)

## 1. 문제 정의
- 교회 북카페/개인 책장 도서를 체계적으로 등록, 대여, 반납, 추적할 수 있는 공통 시스템이 없다.
- 수기/메신저 운영은 반납 누락, 위치 불일치, 연체 대응 지연이 발생한다.
- 대여 이후 참여(서평, 학습, 커뮤니티 활동) 동기가 약해 재방문율이 떨어진다.

## 2. 제품 목표
- 모바일 중심으로 `스캔 1회`로 대출을 완료하고, `반납 + 사진 인증`으로 기록 신뢰도를 높인다.
- 책을 읽은 후 메모/서평/독후감을 남기게 하여 교인 간 지식 순환을 만든다.
- AI 퀴즈와 시상 체계를 통해 사용자가 자발적으로 참여하도록 유도한다.

## 3. 핵심 사용자
- `admin`: 기관 정책, 시상 정책, 분쟁/부정행위 처리.
- `manager`: 북카페/부서 운영자, 반납 검수, 도서 상태 관리.
- `user`: 도서 대출/반납, 개인 도서 공유, 메모 작성, 퀴즈 참여.

## 4. 잘 사용되게 만드는 전제 조건
- ISBN만이 아니라 `권별 고유 코드(copy_code)`를 책마다 부착해야 한다.
- 반납은 `책 코드 스캔 + 서가 코드 스캔 + 반납 사진` 3요소를 최소 수집한다.
- 점수/시상은 단순 정답률이 아니라 `성실 반납 + 메모 + 퀴즈` 복합 점수로 운영한다.

## 5. 단계별 범위

### Phase 1 (MVP, 4~6주)
- 도서 등록:
  - 기관/개인 도서 등록
  - ISBN 조회 자동입력
  - 권별 코드(copy_code), 서가 코드(shelf_code) 관리
- 자율 대출:
  - 사용자 본인 스캔으로 대출 시작
  - 대출 기간, 연체 규칙 적용
- 자율 반납:
  - 책 코드 스캔
  - 서가 코드 스캔
  - 반납 사진 업로드
  - 검수 상태(`pending`, `verified`, `rejected`) 관리
- 운영:
  - 연체 알림, 반납 예정 알림
  - 감사 로그, 기본 통계(대출수/반납지연/활성 사용자)

### Phase 2 (참여 강화, 2~4주)
- 메모/서평/독후감 작성:
  - 공개 범위(`private`, `organization`) 선택
  - 별점/한줄평
- 도서별 활동 피드:
  - 최근 메모, 인기 도서, 재대여율

### Phase 3 (게임화, 3~5주)
- AI 퀴즈:
  - 사용자 수준별 난이도(`beginner`, `intermediate`, `advanced`)
  - 객관식/단답형 문제 생성
  - 풀이 결과 채점/기록
- 시상:
  - 월말/분기말/연말 이벤트
  - 점수 합산 및 랭킹
  - 운영자 수동 보정/확정

## 6. 점수 모델 초안
- 반납 성실도: 최대 40점
- 독서 메모/서평: 최대 30점
- 퀴즈 성취도: 최대 30점
- 패널티:
  - 연체, 반복 무응답, 허위 반납 증빙

## 7. 핵심 KPI
- 4~6주 파일럿 기준:
  - 주간 활성 대여자(WAB) >= 30
  - 반납 완료율 >= 85%
  - 연체율 <= 15%
  - 메모 작성률(대출 대비) >= 35%
  - 퀴즈 참여율(반납 대비) >= 30%
- Go/No-Go:
  - KPI 3개 이상 달성 시 Phase 3 정식 진행

## 8. 운영 정책 초안
- 기본 대여 기간: 14일
- 연장: 1회(7일)
- 반납 검수:
  - 사진/서가코드가 맞으면 `verified`
  - 불일치 시 `rejected` 후 재반납 요청
- 개인 소유 도서:
  - 소유자 승인 기반
  - 분쟁 발생 시 관리자 중재

## 9. 리스크 및 완화
- 리스크: 사진만으로 위치 검증 실패
  - 완화: 서가 코드 스캔을 필수화
- 리스크: 퀴즈 점수 악용
  - 완화: 일일 횟수 제한, 이상 패턴 탐지, 관리자 무효 처리
- 리스크: 운영자 부담 증가
  - 완화: 자동 알림/자동 집계, 검수 큐 우선순위

## 10. 구현 체크리스트
- DB:
  - 도서/대여/반납증빙/메모/퀴즈/포인트/시상 테이블
  - 인덱스, RLS, 업데이트 트리거
- 앱:
  - 대출 스캔 화면
  - 반납 인증 화면(서가 + 사진)
  - 메모 작성 UI
  - 퀴즈 풀이 UI
- 운영:
  - 월간 시상 템플릿
  - 분쟁 대응 가이드
