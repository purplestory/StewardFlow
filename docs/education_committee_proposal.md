# 교육위원회 자원관리 시스템 도입 제안서 (StewardFlow)
## 부제: 유년부 단독 파일럿 운영안

작성일: 2026년 2월 16일  
작성 대상: 교육위원회 위원, 교육부서 담당 목회자

## 1. 제안 배경

현재 교육부서별 물품/공간/차량 운영은 각 부서의 헌신으로 유지되고 있으나, 다음과 같은 반복 이슈가 존재합니다.

1. 필요한 자원의 위치, 상태, 사용 가능 여부를 즉시 파악하기 어려움
2. 대여/반납/양도 요청이 개인 연락 중심으로 진행되어 누락 가능성 존재
3. 담당자 교체 시 인수인계 정보가 분산되어 운영 연속성이 약해짐
4. 연간 예산 집행 이후 자산의 장기 사용/공유 관리가 체계화되기 어려움

본 제안은 새로운 행정 부담을 늘리는 것이 아니라, 기존 절차를 가볍게 디지털화하여 운영 부담을 줄이는 것을 목표로 합니다.

## 2. 현장 우려사항(공감 및 반영)

현장 의견은 타당하며, 아래 우려를 전제로 설계를 조정해야 합니다.

1. 예산은 연 단위로 마감되는데, 자산 운영은 여러 해에 걸쳐 지속됨
2. 누군가가 등록/승인 업무를 지속적으로 맡아야 하므로 책임 부담이 커질 수 있음
3. 운영 규칙이 불명확하면 갈등 또는 비일관 처리 가능성이 생길 수 있음
4. 제도 취지에는 공감하지만, 실제 운영 인력/시간이 충분하지 않을 수 있음

## 3. 운영 원칙(제안)

아래 4가지 원칙으로 도입하면 부담을 줄이면서 실효성을 확보할 수 있습니다.

1. 전면 도입 대신 단계 도입: 처음부터 전체 부서를 대상으로 하지 않음
2. 개인 책임 최소화: 1인 승인 체계가 아닌 역할 기반 분산 체계 적용
3. 최소 등록 원칙: 고가/공유빈도 높은 핵심 자산부터 등록
4. 증거 기반 의사결정: 체감이 아닌 지표(처리시간, 누락 건수, 만족도)로 확대 여부 판단

## 4. 8주 유년부 단독 파일럿 운영안

### 4-1. 범위

1. 대상 부서: 유년부 1개 부서
2. 등록 자산: 핵심 자산 20~30개
3. 대상 기능: 자산 조회, 예약 신청, 승인, 반납, 불용품 양도 요청
4. 제외 기능: 타 부서 확장, 고급 통계/리포트 자동화

### 4-2. 승인 정책(초기 단순안)

1. 기본 정책: 일반 자산 단기 사용은 자동 승인 또는 간소 승인
2. 예외 정책: 고가 자산/차량/장기 대여만 관리자 승인
3. 처리 기준: 승인 대기 48시간 초과 시 자동 알림
4. 부재 대응: 대리 승인자 1인 사전 지정

### 4-3. 역할 분담

1. 유년부 운영 담당(주담당 1인): 자산 등록/상태 갱신/기본 승인 처리
2. 유년부 대리 담당(1인): 주담당 부재 시 승인/반납 처리
3. 담당 목회자: 월 1회 운영 결과 확인 및 예외 기준 조정
4. 사용자(유년부 교역자/부서 임원): 예약 신청, 반납 등록, 요청 사유 기록

## 5. 책임 부담 완화를 위한 장치

1. 운영시간 상한: 담당자 주간 운영시간이 30분을 넘으면 절차 재설계
2. 자동 알림: 승인 대기/반납 지연 건 자동 리마인드
3. 이력 관리: 변경/승인 기록 자동 저장(감사 로그)
4. 대면 갈등 예방: 공개 비판이 아닌 규칙 기반 처리

## 6. 예산 체계와의 정합성

예산 체계(연 단위)와 운영 체계(연속 사용)는 분리하여 관리합니다.

1. 구매/집행은 기존 회계 절차를 그대로 유지
2. 운영 시스템은 사용/대여/반납/상태 이력을 관리
3. 자산에 회계연도 태그를 부여하여 보고 시점에 연도별 조회 가능
4. 결론적으로, 회계를 바꾸지 않고 운영 효율만 개선

## 7. 성공 판단 지표(파일럿 종료 시)

다음 지표를 기준으로 확대 여부를 판단합니다.

1. 예약 승인 평균 처리시간
2. 반납 지연 건수 및 지연 일수
3. 자산 위치/상태 문의 빈도 변화
4. 중복 구매 또는 미활용 자산 발견 건수
5. 담당자 주간 업무시간(체감 포함)
6. 참여자 만족도(간단 설문)
7. 타 부서 문의 건수(도입 상담/데모 요청)

## 8. 리스크 및 대응

1. 초기 입력 부담 증가: 핵심 자산부터 등록하여 부하 제한
2. 승인 병목: 예외 승인 범위를 최소화하고 대리 승인 활성화
3. 규칙 혼선: 승인 기준 1페이지 가이드 배포
4. 참여 저조: 유년부 내부 운영 안정화 후 타 부서 확장 여부 판단

## 9. 교육위원회 의사결정 요청사항

다음 4가지를 결의해 주시면 파일럿을 시작할 수 있습니다.

1. 8주 파일럿 시행 승인
2. 참여 부서를 유년부 단독으로 지정
3. 유년부 주담당 1인, 대리 담당 1인 지정
4. 파일럿 종료 후 확대/보완/중단 중 하나를 지표 기반으로 결정

## 10. 유년부 파일럿 이후 확장 기준(제안)

유년부 파일럿 종료 후 아래 조건을 충족하면 타 부서 확장을 검토합니다.

1. 주담당/대리 담당의 주간 운영시간이 안정적으로 30분 이내
2. 승인/반납 처리 지연이 월 1회 이하
3. 사용자 만족도(간단 설문) 평균 4.0/5.0 이상
4. 타 부서에서 자발적 문의 또는 참여 요청 발생

## 11. 제안 결론

본 제안은 통제를 강화하기 위한 시스템이 아니라, 담당자 부담을 줄이고 부서 간 협업의 예측 가능성을 높이기 위한 최소 운영 장치입니다.  
전면 도입이 아니라 작은 범위의 검증부터 시작하여, 현장에 맞는 방식으로 점진적으로 조정하는 접근을 제안합니다.
